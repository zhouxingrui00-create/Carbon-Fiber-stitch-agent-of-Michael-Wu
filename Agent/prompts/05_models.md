# 阶段5：可解释预测模型、分组验证和适用域

先读长期约束和进度，在现有代码上实施数值训练框架，不微调LLM。

1. 每个目标独立筛选有效标签，支持工艺质量和最终性能两类。先实现Dummy/Ridge基线、RandomForest和GaussianProcessRegressor。数据未提供时所有真实模型保持not_ready，不能自动用合成数据生成“已训练”状态。
2. 明确工艺前模型仅能用当时可知的材料/构型/设备/设定参数。工艺后评估可另建模型使用已测峰值力等信号。缺失目标不得插补成实测标签，测试用随机数据只能放tests/fixtures并标记demo。
3. 默认按材料体系、工艺场景、测试方法/方向和后处理范围建立兼容子集。设计leakage_group_id：同父预制体、相邻运行段、重复记录、共用对照等依赖必要时合并连接分量；不能只拼接多个ID造成同源泄漏。
4. 实现GroupKFold或LeaveOneGroupOut，折数不能超过独立组数。预处理、特征选择和调参都在训练折内，留出外部批次用于声明范围的验证。独立组不足时报告无法可靠评估，不退回逐行随机切分。模型阈值可配置，不用任意行数承诺可靠性。
5. 报告单位明确的MAE/RMSE，条件允许才显示R²。保存折外预测、分组/切分、数据哈希、参数、软件版本和随机种子。区分not_ready/exploratory/validated_for_scope，验证范围明确到目标。
6. GPR输出均值与模型标准差，标注未校准状态；有独立校准/验证后才报告相应覆盖率。不要把森林树间方差、GPR标准差或重复实验标准差混同为合格概率。实现未知类别、范围外和支持稀疏的适用域警告/拒绝。
7. 可做置换重要性等关联解释，明确不是因果证据，不假设缝合越密性能必然越高。

验收：无标签/全部demo/独立组不足时不给真实预测；同源依赖不跨折；工艺前模型拒绝后验特征；目标缺失不伪造；外推提示；固定种子重跑可追溯。测试成绩只能标为软件自测，更新进度后停止。
