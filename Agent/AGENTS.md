## 领域语义
- 线迹/缝合机制、路径图案、运动平台是三个字段。机器人不是独立线迹；人字形是路径。
- “无底线自锁”保留原机构名称；未经机构确认不得归类为常规双线锁式。
- 分开针距 p、行距 s、机械针位间距；分开针频与线速度。
- 分开供纱张力、张力器设定、针线峰值张力、残余张力、面线/底线张力和上下层布面输送张力。
- 分开材料厚度、针刺深度、压脚抬升高度、可稳定缝合厚度；分开定位重复精度、线迹误差、对齐误差。
- 缺失值使用 null 与原因，不以 0 代替。未缝合组 p/s 不适用，不能用 p=0 代入密度公式。
- C/C、C/SiC、聚合物基及不同成型/后处理/测试条件，默认不作为等效标签混训。

## 数值模型与安全
- LLM 负责理解、取证、工具调用和解释；Python 模型负责预测与优化。首版不微调基础 LLM，不堆砌多个聊天 Agent。
- 训练需要有效目标标签；没有目标、独立分组不足或模型未通过验证，必须报告不可用/探索级，不能自动补造标签或随机拆分掩盖问题。
- 使用分组验证；同预制体/同卷材相邻段、重复试样、共用对照和重复文献记录不能泄漏到训练/测试两侧。
- 工艺前推荐模型不能偷用实验完成后才知道的穿刺峰值力、孔隙率、显微损伤等输入。
- 预测不确定度注明方法和验证状态，不等于合格概率或工程保证。超出训练适用域要拒绝或清楚标注。
- 优化器只能在已选定场景、确认的设备可行域、用户批准的试验窗口与模型适用域内提出候选；不得擅自放宽约束。
- 真实设备控制不在首版范围。只做离线分析/只读接口/明确标注的模拟。禁止 PLC 写入、机器人运动和自动执行缝合。
