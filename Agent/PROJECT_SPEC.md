# CF-Stitch Agent：碳纤维预制体缝合工艺研发助手

> 这是需求与开发口令包，不是已经实现或验证的软件。领域数值来自用户两份资料；以下软件架构、数据模型、建模方法和开发顺序是本次设计建议。

## 1. 要解决的问题

建立“材料与构型 → 线迹/机构选择 → 参数窗口审查 → 工艺质量/最终性能预测 → 多目标候选 → 下一轮试验 → 结果回流”的可追溯工作流。优先研究针距 p、行距 s、供纱张力、针径和针频的协同作用，而不是只做资料问答。

主要目标是增进层间性能，同时约束面内损伤、孔隙、断线和制造时间。工程项目另设目标：V 形拼接关注连接质量及强度保留；J 型梁关注 R 角处成迹质量与局部缺陷；双层固定关注错位、滑移与效率。不得用一个未经说明的“综合得分”替代所有物理指标。

## 2. 初期功能与后续能力

无真实数据时必须能用：文档检索与引用、参数词典、来源冲突管理、单位与适用域校验、理论密度计算、空白数据模板、基础试验矩阵、实验记录和缺失项报告。

有合格数据后再启用：按目标训练、分组验证、适用域识别、预测与不确定度、受约束多目标候选、基于预测价值和信息增益的下一轮实验。

不在首版内：基础 LLM 微调、未经验证的 PINN、完整 CAD/机器人运动学仿真、自动碰撞认证、真实机器闭环控制、从普通照片推断内部孔隙率、把文档范围随机采样成“实验数据”。

## 3. 结构化任务与工具

使用一个任务协调器，推荐固定流程优先：

`任务解析 → 补齐关键上下文 → 文档取证 → 参数/设备审查 → 可用性检查 → 计算/预测 → 优化/实验设计 → 审核卡 → 用户确认 → 记录`

建议工具接口：

- `retrieve_evidence(query, scope)`：返回片段、文件哈希、章节和块位置，不只返回结论。
- `validate_task(task)`：输出 PASS/WARN/BLOCK/UNKNOWN，给出字段级理由。
- `compute_geometry(task)`：只做满足假设的密度、针数、轨迹长度、理想运动学计算。
- `predict_targets(task, model_id)`：返回 model_id、目标、单位、样本和分组数、适用域、预测值与不确定度状态；失败时不返回伪数值。
- `propose_candidates(task, policy)`：有合格代理模型时给候选，没模型时退回试验设计。
- `design_experiments(task, budget)`：产生待实验方案，不产生测量结果。
- `summarize_experiment(experiment_id)`：基于实际记录形成报告。

JSON Schema/Pydantic 校验在服务端执行；LLM 不能直接调用任意 Python、SQL、shell 或设备接口。限制工具轮数、超时和重试，保留脱敏调用日志。

## 4. 参数与数据语义

### 4.1 材料/构型背景，不是默认优化旋钮

材料体系、纤维牌号、织物组织、铺层序列、层数、面密度、压实厚度、未压实厚度及其测量条件、纤维体积分数、预制体状态（干态/预浸）、基体、树脂/致密化/热处理条件、部位、背面可达性、边距、模具与夹持方式。

不同场景不得自动混合。厚件窗口 10–30 mm 和薄件窗口 1–5 mm 是资料举例；不能推断 5–10 mm 不可加工。

### 4.2 可调工艺变量

线迹机制、路径图案、针距 p、行距 s、供纱张力设定、针具规格、针径、针尖/针眼、针频、针刺深度、针轴与局部法向夹角。窗口是研究起点；实际上能否调节，还需设备能力记录支持。

缝线记录材料、K 数（适用时）、线密度、捻度、上浆、断裂强力、弯曲耐受性和基体相容性。不把 1K/3K 当成所有线材通用的线密度。

### 4.3 过程测量与目标

实际供纱张力、峰值张力、残余张力、面线/底线张力、布面输送张力、穿刺/拔针力曲线、针距/行距偏差、漏针、断线、孔径、滑移和厚度变化。

后续测量包括断丝、偏转角、孔隙率、缝线体积分数、树脂富集、ILSS、Mode I/II 韧性、厚度向拉伸、面内拉伸/压缩/弯曲和 CAI。只有测过的指标才建立真实标签；目标缺失不能插值制造“实测标签”。

### 4.4 明确禁止混用

- p、s、机械多针间距是不同字段；第一份报告“多针针距”100/120/200 mm 的空间含义待核实。
- 供纱 0.5–10 N / 细纱 0.1–3 N 不等于上下层布面 20–80 N。
- 10–100 针/min 研发起步不等于机器最高 600/800 针/min；二者不冲突，不合并成推荐高速范围。
- 30 mm 抬脚不等于能稳定缝 30 mm 厚料，也不能代替针刺深度。
- 重复定位精度不能直接代替最终线迹精度。

## 5. 三个工程场景的插件

### 5.1 V 形拼接

基础参数沿用 D2 的沿缝针距 3–10 mm。加入 V 角、接缝实际坐标、对接间隙、边距、摆动跨距、定位偏差、夹紧与布面张力；其中未有数值窗口的项目保持未设定，不默认 45°/90° 等。

D1 参考：摆动跨距 5–15 mm、最大针频 800 针/min、最大缝合深度 6 mm、XY 行程 1100/580 mm、重复定位 ±0.05 mm、缝合精度 ±0.3 mm、幅宽 600–1000 mm，强度达到原布料 70%以上是设计目标而不是标签。强度比较必须匹配测试状态与方法，不能把干布连接强力和固化件强度混同。

摆动跨距是幅值还是峰峰值未确认前不得自动换算针位。线迹与路径分离。没有明确几何和夹持包络时，路径显示只能称参数化示意，不能输出机器可执行程序。

### 5.2 J 型梁 R 角

按 D1 保留位置 1、2 固定头与位置 3 六轴机械臂的安排；位置、R 角、局部厚度、法向夹角、路径间距、TCP 标定、夹具/模具空间作为局部上下文。

D1 参考：最大针频 10 Hz = 600 针/min，深度 30 mm，机头 240×100×65 mm、约 2.5 kg、200 W；记录而不据此宣称机器人负载或碰撞可行。缺少机型、安装包络、重心、载荷和标定时返回可达性未验证。

D1 “5–15 针/cm”按均匀单排计数可导出 p≈0.667–2 mm，与 D2 通用 3–15 mm 不同。保留原量、推导假设和审核状态，不自动纳入优化。无底线自锁保持 custom_unconfirmed。

### 5.3 双层叠层固定

加入上/下布面张力、张力差、线速度差、EPC 偏差、压辊/压脚设定、机械针位间距与并行轨迹数。张力差作为派生特征，而非替代两层原始张力。

D1 参考：布面张力初始 20–80 N、针距 10–30 mm、初始针频 100–500 针/min、叠层错位目标≤0.5 mm、幅宽 600–1000 mm。不要把该固定工艺针距强行裁成通用窗口 3–15 mm；分别保存、由用户批准场景窗口。

D1 的 5/6 mm 厚度、链式/双线自锁描述、1200 与 1500–2000 mm 空间描述均保留冲突。确认前不生成无条件合格结论。

## 6. 数值计算

规则矩形阵列、每单元一个穿刺点时，N_A=10^6/(p*s)，p/s 为 mm，输出点/m²。不包括额外回针、双针、锁固和边界效应；复杂路径按真实针位/实际面积计算。未缝合状态可明示理论密度 0，但不能经 p=0 运算。

理想直线同步送料且每周期一针、p 就是送料方向实际每针前进量时，v=p*f/1000，v 为 m/min，f 为针/min。不能用曲线弧长针距或摆动跨距代替送料间距。有限试件总针数需明确尺寸、边距和边界包含规则；并行机头的节拍要按实际调度计算，不机械按针数除以机头数。

匹配对照下提升率=(缝合组均值-对照均值)/对照均值*100%。对照不匹配、为零或缺失，返回不可计算。损失率使用相反符号，并明确正值表示损失；负值代表提高，不能静默截断。分母共享与重复测量必须在验证分组中保留依赖关系。

这些是结构/运动学/统计计算，不是强度本构模型；首版称“工艺约束与几何特征辅助 ML”，不冒充经过验证的物理信息神经网络。

## 7. 数据存储与训练

建议本地 Python + Streamlit + SQLite/SQLAlchemy + pandas + Pydantic + scikit-learn。先以 CPU 可运行、少依赖为目标。DOCX 用结构化段落/表格抽取；PDF 仅在实现并验证提取后启用。离线全文检索优先，向量检索可做可选增强，不为首版强制安装大型模型。

建议规范化实体：sources、materials、equipment_profiles、trial_plans、process_runs、specimens、measurements、sensor_files、dataset_versions、model_runs、candidate_sets、reviews。简易导入视图不能抹掉父预制体/批次/来源/对照关系。

每条 measurement 含 metric_name、value、unit、measurement_stage、method/standard、加载方向、试样几何、失效模式、uncertainty/重复数和 raw_data_ref。计数率必须保存分子、分母与观察窗口。

标签 provenance 至少分 experimental_measured、literature_measured、simulation、demo、prediction。仿真和实验不默认混训；文献均值不要伪扩增成多个试样。导入做重复识别和事务回滚，原始资料只读。

模型分两条路：工艺前仅用已知材料、几何、装备和设定参数；工艺后可显式使用已测过程信号。首版分别用 Dummy/Ridge 作基线、RandomForest 作非线性对照、GaussianProcessRegressor 作带模型不确定度的候选；每个目标各自筛选有效标签。GPR 和森林不设“谁必胜”的结论，按验证选择。

分组依据实际依赖关系确定：同预制体切片、同连续运行相邻段、共用对照、同来源复制记录等必要时建立连接分量 leakage_group_id；按所声明泛化目标保留外部批次/文献作为验证。所有预处理、调参、特征选择只能在训练折内。分组不足时不能退回逐行随机切分来制造好成绩。

显示 MAE/RMSE（带单位），目标方差和测试样本允许时报告 R²。保存每折误差、原始预测、配置、软件版本、数据哈希、随机种子及适用域。模型不确定度与重复测量标准差分开；GPR 标准差不自动等同校准后的 95% 覆盖区间或合格概率。

状态建议：not_ready / exploratory / validated_for_scope。后两者阈值与评估策略由研究者确认；不能把任意行数门槛宣传为科学保证。

## 8. 试验与优化

D2 第 11 页矩阵原样作为“约 20–25 mm 预制体、锁式/链式、其他条件一致”的模板，不能直接用于最高 6 mm 的 V 拼接机。7 个组别不是 7 个足够统计的样本；重复数、独立制样数、随机化/区组安排、测试方案由用户确认。

阶段性研究建议：先做低速穿刺/针线匹配筛查，再固定已筛选的针径/张力/速度研究线迹×p×s，之后对主要因素做局部响应优化。不要在最初七组同时更改十余变量。

无模型时生成有来源的矩阵或用户批准的空间填充设计；有合格模型后对设备允许的离散针线组合和连续参数空间搜索。保留 ILSS/Mode I/Mode II 等目标以及面内损失、孔隙率、断线、耗时等约束，阈值缺失必须显示。输出 Pareto 候选而非声称全局最优。无可行候选时报告冲突，不偷偷放宽。

下一轮实验分清“预期改进候选”和“降低不确定性候选”；含基准重复，记录 experiment_id 与 proposal_id。盲测新试验用于评价推荐效果，不能把模型自己的预测当作新真实数据回填。

## 9. UI、隐私与交付

建议页签：任务工作台、资料与参数、试验设计、数据管理、模型训练、预测优化、三场景配置、结果报告、设置。首版可合并页面以避免空壳。

建议端口 8502；提供一键启动 bat 和终端启动命令。先探测当前解释器与依赖，不要求用户手工编辑大量脚本。基础离线功能不可依赖 API Key。

云端 LLM 为可选项：base_url、model、api_key、timeout 可配置；请求前展示将发送的文档片段/字段并征求授权。默认不发整份技术报告或实验原始数据。提供本地 provider 接口，但本机模型没安装不能假称已可用。不硬编码具体型号和计费承诺。

导出工艺卡应带“研究建议，未经实验/设备确认不可上机”、来源、假设、冲突、适用域、候选参数、缺失数据和人工审核状态。

## 10. 开发门槛

每阶段写实际测试结果，不把模拟 API 成功当成真实网络成功，不把后台启动进程当成 UI 交互全部通过。验收覆盖无数据、缺参数、来源冲突、非法单位、设备不适配、数据泄漏、外推、无可行解、API 失败和文档注入等异常。

推荐先完成阶段 1–4，得到不靠假数据也能工作的实验助手；再完成阶段 5–7，接入真实训练与预测闭环。
