# 第 4 阶段实验计划与空白记录模板

- `daily_measurements.xlsx`：26列中文日常简化版，适用于单个试样的普通标量指标；结果全为空。导入时选择“日常记录”，按第二个工作表“填写说明”的中文表头/字段代码对照手工映射。此表不用于文献均值、仿真、预测或计数率；详细设备、厚度、针径、张力、针频等信息使用完整模板。
- `seven_group_plan.json`：完整待实验计划、来源哈希、适用背景、匹配条件、缺项与分步建议。
- `seven_group_plan.csv`：同一计划的七组清单。C0 未缝合；L1/L2/L3 锁式与 C1/C2/C3 链式均为 5×5、5×10、10×10 mm。计划 CSV 不是测量导入文件。
- `blank_measurements.csv` / `blank_measurements.xlsx`：仅字段表头，没有示例试样或测量。Excel 选择“数据”工作表导入；“填写说明”提供逐字段解释。

页面下载入口：**数据管理 → 导入预览 → 导入字段说明与空白模板 → 下载日常简化版 Excel（26列中文）**。实验设计页的“下载待实验清单与空白录入模板”也提供同一文件。正式文件与 `outputs/daily-template-20260920/CF-Stitch_日常简化记录表.xlsx` 内容相同，页面从本模板目录读取，不依赖输出目录。

七组来源为第二份文档 `D2:t006`，约 20–25 mm 厚件背景。要求匹配材料、纱线、铺层、压实、成型/后处理与未缝合对照。重复数、独立制样数、针径、张力、速度、测试方法和加载方向等待用户确认，全部留空。模板不是七个独立样本，不可训练，也没有批准执行。

先做低速穿刺与针线匹配筛查；由研究者确认数值条件后固定其余参数，再比较机制与 p/s。设备能力未确认时不能批准；例如适用的稳定缝合厚度确认上限为 6 mm 时，阻断 20–25 mm 计划，原模板仍保留。

未知数值留空，导入后为 null；只有真实零才填 0。未缝合的 p/s 留空。结果为空时填写 `missing_reason`。设定在 `*_setting_*` 列，实际结果另存 `metric_name/value/unit/measurement_stage`，不得覆盖设定。

`provenance` 必填且分开实验实测、文献实测、仿真、演示和预测。文献均值使用 `aggregate`，保留原始文献记录编号和报告样本数，不复制成多个独立试样。demo 仅进入 demo 空间。原文件保留，导入先核对映射及错误，再执行事务写入。

导入枚举需明确填写：`aggregation_level` 用 `individual` 或 `aggregate`；未知 `path_pattern`/`motion_platform` 用 `unspecified`；普通指标 `metric_kind=scalar`，计数率则 `count_rate` 并保留分子、分母与观察窗口。已有结果应填写实际测量阶段与单位。

Excel 为纯值模板，不含公式、合并单元格、宏或外部链接。不要将七组计划填进测量表充当实验结果。
